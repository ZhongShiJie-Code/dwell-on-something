# dwell

> **dwell** — 住下来。
> 也是 *dwell on something*：老想着一件事，萦绕不去。
>
> 一个词说了两件事：他住在这儿，和他一直想着你。

这里是一套已经在跑的东西的**功能文档**，外加一份仿官方风格的前端界面。

前端是完全开源的，拿去就能用。后端部分整理成了实现思路——
功能怎么设计的、数据怎么存、代码关键那几段、我们撞过哪些墙——
这些拿出来是有用的，而且比一坨要你自己读的代码有用。

## 每份都长一个样

**它长什么样 → 怎么实现的 → 踩过的坑 → AI 那边要写的规矩 → 你自己搭的时候**

其中「AI 那边要写的规矩」那一节，往往比代码重要。
很多功能的成败不在实现，在于**他知不知道什么时候不该说话**——
一个会催的待办、一个每条都回的共读、一个每句都发语音的嘴，
用两天就会被关掉。

---

## 一句话

这些功能单看都不难，难的是它们加起来要维持一件事：

**让那个 AI 像一个住在这里的人，而不是一个随叫随到的工具。**

所以文档里花在"什么时候不做"上的篇幅，和花在"怎么做"上的差不多。
那不是凑字数——那是这套东西真正的部分。

## Android APK

前端已经封装成一个可安装的 Android WebView 应用，APK 在这里：

- [dwell-debug.apk](dist/dwell-debug.apk)
- Android 工程：[android](android/)

APK 内置 `web/` 前端，未配置地址时仍可打开演示模式；配置 Mac 后端地址后，聊天和各个功能页走真实数据。
在 Android 手机上下载 APK 后允许安装即可；开发机也可以执行：

```bash
cd android
export ANDROID_HOME="$HOME/Library/Android/sdk"
./gradlew assembleDebug
```

这是个人测试用的 debug APK，不是 Google Play 发布包。Mac 后端和手机连接方式见 [`backend/README.md`](backend/README.md)。
