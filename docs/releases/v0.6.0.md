# Dwell v0.6.0

## 安装

- 下载 `dwell-v0.6.0.apk`，在 Android 手机上允许浏览器或文件管理器安装未知应用后安装。
- v0.4.7 及更早版本使用 debug 签名，升级到 v0.6.0 必须先卸载旧版一次；v0.6.0 以后可覆盖升级。
- 安装后在 Mac 后端执行 `cd backend && npm run pair`，在手机中输入六位配对码。

## 本次更新

- Compose 原生聊天、会话列表、模型选择、侧栏、定时任务、设置、语音和通知。
- SQLite WAL 持久化，首次启动自动备份并迁移旧 JSON/JSONL 数据。
- REST v2 与 SSE 流式回复，支持断线重放与局域网/Cloudflare 快速回退。
- 同步 Mac Claude Code 会话，重新生成保留旧答案版本，消息时间、反馈、归档和恢复可用。
- 定时任务详情、运行记录、手动运行/暂停；真实任务测试仅限 `Github trending backup`。
- 原生语音识别兜底、Markdown 安全朗读、系统明暗主题跟随、崩溃循环安全模式。
- WorkManager 后台通知补偿与通知诊断。

## 已知边界

- 未配置 Firebase Cloud Messaging 时，应用被系统彻底杀死后没有秒级推送；后台补偿可能受 Android 省电策略影响，最长约 15 分钟。
- 待办、日历、日记、共读、日报、健康和仓库暂时通过受控 Legacy WebView 运行，后续版本再逐页原生化。
- 本版本已通过后端自动测试、Android 单元测试、Lint、签名和 APK 结构检查；Samsung S25+ 真机安装与手感仍需在手机上最终验收。
