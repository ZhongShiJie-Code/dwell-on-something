# 前端源码

`index.html` 就是**完整的前端**——不是演示片段。
HTML、CSS、JavaScript 全在这一个文件里，没有构建步骤、
没有依赖、没有 node_modules。改完刷新就生效。

现在这份前端也带了 Android/PWA 所需的 `manifest.json`、`sw.js` 和图标。
浏览器版可以添加到主屏幕；仓库根目录的 `android/` 工程会把整个 `web/`
目录直接打进 APK，前端只维护一份。

APK 构建：

```bash
cd ../android
./gradlew assembleDebug
```

## 直接打开就能看

文件里带了一份写死的演示数据，所以**双击就能在浏览器里跑**，
不用接任何后端。而且它**不会向外发出任何请求**——
所有 `api/` 调用都被那份演示数据拦下了。

## 接仓库里的后端

不需要删除或改写演示代码。用 `backend/server.mjs` 启动服务后，从
`http://127.0.0.1:8787/` 打开就是同源真实模式；APK 则在「设置 → 接入 API」
填写 Mac 地址。只有 `file://` 且没有保存后端地址时才会启用离线演示。

## 字体

`fonts/` 内嵌了 GitHub 开源字体 `Inter` 和 `Cormorant Garamond`，分别用于
界面文字和 Claude 风格的欢迎语排版；对应的许可证文件也一并保留在该目录。
它们是 Anthropic 官方字体的开源替代，不依赖网络加载。

## 里面有什么

聊天主界面（流式、思维链、工具调用、代码块、图片、文件卡片、音乐卡片）、
顶上的弹窗、干活时那行动作词、液态玻璃那套皮、锁屏、
日记 / 待办 / 日历 / 日报 / 共读 / 健康 / 仓库 / 悄悄话各页、
模型切换、搜索、容量、用量、窗口列表。

设置、连接测试、项目、工具权限和连接器状态也包含在内。
